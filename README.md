 🏬 Mall Stall Management System

 📌 Description
A simple web-based application to manage mall stalls.  
Users can add stall details, and the data is stored in a real-time database.

 🚀 Features
- Add stall name and owner details
- Real-time data storage using Firebase
- Instant display of stored data
- User-friendly interface

🛠️ Tech Stack
- HTML
- CSS
- JavaScript
- Firebase Realtime Database

 📂 Project Structure
mall-stall-management/
│
├── index.html
├── style.css
└── script.js


 🔥 How It Works
1. Enter stall name and owner
2. Click on "Add Stall"
3. Data is stored in Firebase database
4. Data is displayed instantly on the page

 📊 Database
The project uses Firebase Realtime Database to store stall details in JSON format.

Example:
stalls
  -randomID
    name: Wow Momos!
    owner: Riya Sharma

⚠️ Note
Firebase rules are set in test mode for development purposes.
